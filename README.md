# Neil Fernandez | Control Plane

Interactive resume site built with Vite and vanilla JavaScript.

## Development

```bash
npm install
npm run dev
```

The dev server runs at `http://127.0.0.1:5173/` by default.

## Build

```bash
npm run build
```

Vite writes the production site to `dist/`. GitHub Actions builds and deploys that folder to GitHub Pages.
